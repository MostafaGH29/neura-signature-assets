# neura-signature-assets

Public visual assets for Neura AI email signatures, served via GitHub Pages.

| File | Description |
|---|---|
| `v1.0.0/motion/neura-motion.gif` | "Neura / Cinematic Intelligence" motion strip. 880×192 px (displayed at 440×96), 80 frames, 4 s infinite loop, greyscale. |
| `v1.0.0/motion/neura-motion-first-frame.png` | Static first frame (fallback preview). |

## Versioning

Production URL (v1.0.0):

`https://mostafagh29.github.io/neura-signature-assets/v1.0.0/motion/neura-motion.gif`

Each release lives in its own versioned folder, and the git tag of the same name marks it. **Published versions are never modified, moved or deleted**, because emails that have already been sent keep referencing them. Changes are published in a new folder and tag (for example `v1.1.0/`), and only new signatures use the new URL.
